This is a collection of *minecraft-related*, guided, easy beginner coding mini-projects. If you like minecraft commands and want to learn to code, you might like this.

Project overview:
1. [Generating particle commands](https://github.com/Avvvvvvie/minecraft-coding-tutorials/blob/main/1/README.md): Generate particle commands based on calculations that would be tedious to do by hand.
2. [Looking up a minecraft profile](https://github.com/Avvvvvvie/minecraft-coding-tutorials/blob/main/2/README.md): Create a website where you can look up a players UUID and skin.
3. [Creating a tool that sets up a new datapack](https://github.com/Avvvvvvie/minecraft-coding-tutorials/blob/main/3/README.md): Create a console comand on your computer that sets up the files and folders for a new datapack.
